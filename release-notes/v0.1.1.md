- Add selected songs to a playlist or Spotify Liked Songs from the `Ctrl+Z` menu.
  Press `Ctrl+S`, then `l` to like selected or marked songs. Use `Ctrl+S`, then
  `L` for the currently playing song.
- Remove songs from Liked Songs through the context menu or `D` in the Liked
  Songs page, with confirmation and an immediate list refresh.
  The context menu shows only the applicable add or remove action. Library
  changes refresh quietly, keeping the specific save or removal confirmation.
- Sort songs within playlists, albums and Liked Songs. Each collection remembers
  its view order across restarts. Spotify's playlist order stays unchanged.
  Use `sr` for recently added, `st` for title, `sa` for artist, `sA` for album,
  `sd` for duration, `so` for original order and `ss` to reverse. Stop moves to `S`.
- Save albums and follow artists from the context menu. Saved items offer
  removal or unfollowing, with confirmation.
- Mark items with `m` without moving the cursor. Marked rows show a spaced `M`
  prefix.
- Navigation shortcuts follow the configured tab order. The default bar is
  Queue, Artists, Liked Songs, Albums, Playlists, Directories, Search.
- Prepare library tabs and the current song's cover before their first visit.
  Reuse encoded artwork when returning to Queue and avoid expensive image work
  during redraws.
- Keep context menus responsive while library actions load in the background.
  Queue redraws check album boundaries only for visible rows, and playback
  details remain correct when a large queue is reordered.
- Fix recommendations taking over the queue after a song ends, stale server
  capabilities after reconnecting, delayed Liked Songs updates, and deletion of
  multiple songs from a sorted playlist.
- Keep selection colors consistent and prevent the status bars from shifting
  when typing commands or changing playback state.
- Group library, sorting and selection shortcuts separately in the keybind popup.

After upgrading, restart the daemon once with `rspc stop`, then open `rspc` again
to load the new library commands and addition dates. Stopping the daemon ends
current playback. Existing custom configurations are preserved.

Download your platform's archive and `SHA256SUMS`, verify the checksum, and follow
the [installation instructions](https://github.com/nathanaelluke/rspc/blob/v0.1.1/README.md#install).
Each binary archive includes both rspc executables.
