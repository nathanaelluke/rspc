The first release of rspc, a terminal music player for Spotify, local files and
streams, with an interface derived from rmpc.

- Browse saved albums, followed artists, liked songs and playlists.
- Put Spotify tracks, local files and streams in one queue.
- Keep playback running when you close the interface.
- Customize themes, layouts and keybindings with rmpc-compatible configuration.

Downloads are available for Linux x86-64, Linux AArch64 and Apple Silicon macOS
13 or newer. Native Windows and Spotify playback on Intel Macs are not supported.
Linux binaries require OpenSSL 3 and glibc 2.35 on x86-64 or 2.39 on AArch64.

Download your platform's archive and `SHA256SUMS`, verify the checksum, and follow the
[installation instructions](https://github.com/nathanaelluke/rspc/blob/v0.1.0/README.md#install).
The archive includes the complete application. Run `rspc` to launch it.
The `source` archive includes vendored Cargo dependencies for offline rebuilding.
Package-manager publication is tracked separately; see the README for availability.

Spotify playback requires Spotify Premium, your own Soloist API key and a
separate Soloist installation. Run `rspc login` after
[setting up the key](https://github.com/nathanaelluke/rspc/blob/v0.1.0/README.md#spotify-setup).
Soloist builds expire, so keep the player updated. Local files and streams use
MPD 0.24 or newer. Switching between Spotify and MPD has a short playback gap.

Report problems in [GitHub Issues](https://github.com/nathanaelluke/rspc/issues).
Include the platform, rspc version and steps to reproduce. Inspect diagnostics
before sharing: logs can contain local paths and library metadata. Do not attach
API keys, credentials or pairing state.
