## Local files and playback

- Browse local files alongside Spotify in Search, Albums, and Artists. When
  Spotify and MPD return the same track, rspc prefers the local copy and keeps
  distinct discs and track positions.
- Keep the selected volume when switching between Spotify and MPD. Reapply it
  when MPD opens a PulseAudio stream at a different level.
- Recover expired MPD connections and resume the same track and position after
  an MPD restart. Paused tracks stay paused. Local seeks retry briefly while
  the decoder opens.
- Apply the configured MPD timeout during the initial connection and retry
  volume briefly when a PulseAudio mixer is still connecting.

## Library and queue

- Keep the query, results, and selection when liking a track from Search.
  The default shortcut `Ctrl+S`, then `l` toggles selected or marked
  Spotify tracks.
- Open the `Ctrl+Z` menu with its library actions already resolved.
- Sample random additions from Spotify Liked Songs, saved albums, and the local
  library.
- Press `Shift+V` to select a contiguous range of songs. Move marked tracks with
  `J` and `K`, or use the selection with queue and playlist actions.
- Preserve queue marks when tracks move, keep shuffle traversal consistent, and
  report the next scheduled track. Validate playlist replacements before
  replacing the saved playlist.
- Honor the requested queue position when loading a saved playlist, reject
  invalid destinations, and accept legacy MPD tag and value searches.
- Keep playlist-name drafts through database refreshes and prefill the
  existing name when renaming a playlist.

## Artwork and popups

- Load full-quality embedded covers in fewer MPD requests. Kitty uses faster
  lossless compression and reuses the previously displayed cover.
- Use a crisp grayscale placeholder when album artwork is unavailable.
- Keep Song info and Selection info readable on ultrawide terminals. Set
  `song_info_max_aspect_ratio` for Song info and `modal_max_aspect_ratio` for
  Selection info, Keybinds, and Decoder plugins. Both default to a visual
  ratio of 2:1. Set either to `None` to disable its limit.

## Upgrading

After installing the update, run `rspc stop` and reopen `rspc` to load the
new daemon. This stops current playback. Local files and streams require a
running MPD 0.24 or newer. rspc connects to the address in the existing MPD
configuration.

Download both your platform's archive and `SHA256SUMS` and verify the
checksum before installing. Each binary archive contains both rspc executables.
[Installation instructions](https://github.com/nathanaelluke/rspc/blob/v0.1.2/README.md#install).
